YCode 图标方案

四个方向，均按 macOS 图标网格（824px 圆角方块，内缩 100px）绘制。每个方案展示 128 / 64 / 32 / 16 像素在浅色与深色背景下的效果。

第六轮：面向输入框交互（基于 F3）

F3. 提示符 Y（原版）

白色 ∨ 加深墨色的方块光标，方块光标带终端意味。

G1. 输入光标 Y

造型同 F3，把方块光标换成细长的文本插入光标，任何输入框里都有，不再绑定终端。

G2. 输入框 Y

白色圆角输入框里是 Y 形光标，右侧发送按钮上是 AI 星芒。

G3. 对话气泡 Y

Y 形光标放在对话气泡里，表达和 Agent 对话，右下角星芒。

第五轮：扁平风格（纯色，无渐变、发光与阴影）

F1. 色块 Y

珊瑚红、向日葵黄、薄荷绿三根圆头色条拼成 Y，白色星芒嵌在两臂的 V 形缺口里。电光紫底。

F2. Agent 小脸

三个带表情的彩色小 Agent 用深色连线连成 Y，中心是星芒。向日葵黄底。

F3. 提示符 Y

白色 ∨ 提示符加深墨色光标块组成 Y，旁边一颗黄色星芒。珊瑚红底。

F4. 三色星芒 Y

三角星芒排成 Y，每个角一种纯色，中心白点，右上角薄荷绿小星芒。深墨色底。

第四轮：3D 拟物质感（物理渲染）

3D-1. 糖果 Y

一整块亮面糖果做成的 Y，洋红、青蓝、琥珀三色在交汇处融合，右下角一颗发光的 AI 星芒。电光蓝底座。

3D-2. 霓虹玻璃 Y

磨砂玻璃做成的 Y，每条臂里有一根彩色霓虹灯管，中心是白色 AI 核心，光在玻璃里散开。深靛蓝底座。

3D-3. Agent 分子

三颗亮面糖果球代表三个 Agent，用铬金属管连成 Y，交汇处是玻璃包着的发光核心。珊瑚橙底座。

第三轮方案：鲜明配色 + AI Agent + 字母 Y

Ⅰ. Y 形星芒

三个角的 AI 星芒排成 Y，洋红、青蓝、琥珀三色在中心汇成白光。AI 与 Y 是同一个图形。

Ⅱ. 提示符 Y

终端提示符 > 转成 ∨，下接一个光标块，合起来就是 Y。多色融合底加两颗星芒。

Ⅲ. Y 天线机器人

终端屏幕做成机器人的脸，天线分叉成 Y，两个尖端各一颗金色星芒。

Ⅳ. Y 形 Agent 网络

三个彩色终端窗（Agent）连成 Y，中心是 AI 星芒。紫到珊瑚红渐变底。

第二轮方案

A. Agent 轨道

中心发光的 AI 核心，三个彩色 Agent 卫星沿交叉轨道环绕。橙粉紫渐变底。

B. 提示符 + 星芒

粗白色 > 提示符，光标位置是一颗金色大星芒。青、橙、粉、紫多色融合底。

C. Agent 机器人

终端屏幕做成机器人的脸，发光的眼睛和微笑，天线顶端是星芒。青绿到蓝紫渐变底。

D. 叠层窗格

洋红、青蓝、明黄三块半透明窗格叠加，重叠处混出新颜色，中心是星芒。

第一轮方案

定稿：输入光标 Y（G1，线宽 80）

白色 ∨ 和深墨色文本光标用同一线宽组成 Y，黄色星芒代表 AI Agent。扁平纯色，珊瑚红底。光标是输入框的通用元素，产品从终端转向输入框交互后依然适用。已用于 App、网站和介绍视频。

1. Y 形 Agent 网络

三个彩色 Agent 节点连到中心的 AI 星芒，连线组成字母 Y。紫到珊瑚红渐变底。

2. 四窗格 + 星芒

2×2 四色窗格对应多会话画布，每格一个终端提示符，中心是 AI 星芒。深靛蓝底让颜色更跳。

3. 霓虹立方体

延续现有立方体（三个面交汇成 Y），换成琥珀、洋红、青蓝三色，右上角加星芒。

4. 终端 + 星芒

白色终端窗口里是 >_ 提示符，右上角一个金色星芒。青到紫渐变底。
