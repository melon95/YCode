# Computer Use 研究状态

更新：2026-10-17。后续独立研究，尚未立项，也不属于当前 CLI 工作台的交付或发布门槛。

## 保留的研究方向

在用户明确授权的情况下，让现有 Agent 会话发现应用与窗口、观察界面、执行基本操作并核对结果。Tandock 可提供原生执行服务，Agent 通过独立的工具接口调用；是否开发及具体接入方式以后另行确定。

需要研究的边界：

- 应用与窗口的发现、可访问性信息及截图。
- 点击、输入、快捷键和滚动的实际可用性，尤其是后台操作。
- 系统权限、目标应用授权、操作记录与停止能力。
- 浏览器与桌面操作各自的限制，以及真实界面验收方式。

## 后续立项条件

以届时实际工作的 CLI、工具接口和主线架构重新确认范围，先验证原生可行性，再决定是否实施。没有固定引擎组合、前置迁移阶段或既定里程碑。

当前没有实现完成或发布承诺；现有原型与公开参考不能代替实际执行验证。
