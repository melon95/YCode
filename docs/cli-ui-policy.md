# CLI 会话界面规则

更新：2026-10-18。当前以 `main` 的真实 CLI 终端工作台为准。

## 当前界面

- Claude Code、Codex、Pi 和自定义 CLI 使用各自的交互式 PTY 终端。
- 不同 CLI 的会话可以在同一画布并存；项目 Shell 与 Agent 会话分别管理。
- 每个 CLI 保留自身的工具、配置、登录与上下文，不统一改用某个引擎执行。
- 终端中的命令、输入与确认由 CLI 处理，不从终端文本推测结构化审批或模型完成状态。
- 恢复保持原会话来源；无法恢复时明确提示，不在另一引擎静默续跑。

## 独立分支

原生会话界面与统一输入入口保留在 `codex/unified-session-entry`，当前暂缓，不作为主线待办或发布门槛。相关实现、设计和验收记录在该分支维护。

未来如恢复自定义界面工作，仍按各 CLI 自身的结构化接口逐个适配，不引入应用级互斥模式，也不自动转换已有终端会话。

当前功能与检查场景分别见[产品范围](tandock-feature-spec.md)和[验收清单](bdd-iteration-plan.md)。
