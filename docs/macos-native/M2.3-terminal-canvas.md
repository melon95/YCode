# M2.3 原生终端画布验收

状态：**通过**

环境：macOS 26.6.2 arm64；Swift 6.3；SwiftTerm 1.20.0；独立测试数据目录

## 实现

- SwiftTerm `TerminalView` 通过窄 `NSViewRepresentable` 桥接接入应用级会话池；SwiftUI 视图销毁只解除显示绑定，不停止 PTY 或 Agent。
- 会话进程与画布分离，保留 256 KiB 原始字节回放缓冲；终端首次得到有效尺寸后重放，避免零尺寸初始化导致内容不可见。
- 画布支持单栏、堆叠、多列、2×2、主副五种布局，并按 1–4 个可见会话自动限制可选模式和回流。
- 终端输入、尺寸同步、复制粘贴、搜索、动态字号、OSC 标题及链接回调均接入 SwiftTerm；终端搜索提供匹配序号和“无匹配”反馈。
- URL、`mailto:`、绝对路径和项目相对路径统一解析；文件路径支持 `:line[:column]`，不存在的路径不触发跳转。
- 终端、文件、变更、待办四个面板及 ⌘1–4、⇧⌘1–4 快捷键已接入；尚未迁移的面板内容明确标注其后续步骤，不伪装为可用功能。
