# M4.3 语法高亮与原生内容预览

日期：2026-09-17
状态：通过

## 实现结果

- 继续使用 TextKit 2 编辑器，通过窄 `NSViewRepresentable` 给 `NSTextStorage` 应用原生属性，不更换 M4.2 的标签、撤销和保存模型。
- 建立唯一语言注册表，覆盖旧版清单的 39 组语言、全部扩展名、Ruby/Dockerfile 特殊文件名及既有缩进宽度。
- 高亮器离线识别注释、字符串、数字、关键字及 Markdown、HTML/XML、YAML/TOML/Properties、Diff 的结构 token；80 ms 防抖后在后台计算，只在文本版本仍一致时回到主线程应用。
- Markdown 使用固定版本 `swift-markdown` 0.8.0 解析，由 AppKit 富文本渲染标题、段落、列表、任务列表、引用、表格、代码及行内样式；原始 HTML 不执行。
- PNG/JPEG/GIF/WebP/BMP/ICO/AVIF/APNG 与 SVG 均由 `NSImage` / `NSImageView` 解码显示；动画图片允许由系统图像视图播放。
- Markdown 与 SVG 默认进入预览并可切回源码；位图以只读图片方式打开；未知文本扩展名保持普通编辑器，不显示空白页。
- 损坏图片和非法 SVG 显示明确错误；SVG 仍可切回源码修复。整个渲染链不包含 `WKWebView`。

## 架构修订

M0.4 曾预选 `SwiftTreeSitter`。M4.3 正式集成时，没有找到同时满足 39 组完整覆盖、离线运行和固定依赖的现成 Swift 语法包：低层封装需要逐语法维护 C target，完整语言包则依赖首次下载。当前改为自有离线 token 扫描器，确保既定清单全部有高亮和可复现测试；它不宣称具备 Tree-sitter AST 精度。M4.4 接入 LSP 后再叠加语义 token，而不是把联网下载或不完整语法包带入首版。

调研依据：[`swift-tree-sitter`](https://github.com/tree-sitter/swift-tree-sitter)、[`TreeSitterLanguages`](https://github.com/simonbs/treesitterlanguages)、[`tree-sitter-language-pack`](https://github.com/xberg-io/tree-sitter-language-pack)。
