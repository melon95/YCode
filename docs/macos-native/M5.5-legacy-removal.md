# M5.5 移除旧实现和其他平台构建

状态：冻结（2026-09-20 修订前置条件）

## 前置条件

原前置条件为"M5.1–M5.4 全部通过"。在证书后置、以本地自用为目标的排期下，这条会产生一个错误结论：等证书到手、M5.4b 通过就可以删旧实现——而那时原生版可能才自用了几天。

**本地自用期恰恰是最需要旧版兜底的时期**：切换后旧 app 移入快照目录，它是唯一的回退手段。因此前置条件改为同时满足两条：

1. M5.1–M5.4（含 M5.3b、M5.4b）全部通过；
2. 原生版连续日常自用满 4 周，且期间零回退。

当前状态：M5.2、M5.3a、M5.4a 已通过；M5.3b、M5.4b 后置；自用观察期尚未开始计。两条前置均未满足。

## 当前处理

- 未删除 `src/`、`src-tauri/`、旧 Rust crates、旧发布配置或旧版回退材料。
- 原生实现、候选包、切换脚本和验收文档与旧实现并存，保证仍可定位和回退。
- 不把“原生包可以构建”当成允许删除旧实现的依据。

## 解除阻塞后的操作

1. 固化最后一个旧版发布标识、构建方式、数据路径和回退包。
2. 删除只服务于旧 Tauri/React 应用及非 macOS 平台的构建入口，同时保留仍被原生迁移工具需要的数据格式说明。
3. 从干净检出重新构建、签名、安装和启动原生包。
4. 重跑核心回归，检查正式包不再包含或调用 WebView、Tauri 或旧 Rust 应用二进制。

## 结论

前置条件未满足，M5.5 保持冻结；本步骤没有提前删除任何旧实现。本地自用期内旧 app 与切换前数据是唯一回退手段，删除动作必须等到自用观察期结束。
