# M2.2 会话进程池与生命周期验收

状态：**通过**

环境：macOS 26.6.2 arm64；Swift 6.3；原生开发数据副本

## 实现

- 应用级 `YCodeSessionProcessPool` 独立持有 `LocalProcess`、终端状态和 256 KiB 输出回放缓冲；切换项目或重建视图不会重复启动进程。
- 新建、停止、恢复/重启、重命名与归档均通过 `YCodeAgentSessionService` 统一处理，并同步 SQLite 会话元数据、退出状态和原生 Agent 会话 ID。
- 停止向 forkpty 进程组发送 `SIGHUP`，超时后强制回收，避免 Agent 的子进程残留。
- Claude 新会话使用 `--session-id`，恢复使用 `--resume`；Codex 恢复使用 `resume <会话 ID>`；Gemini 恢复使用 `--resume`，与旧版参数约定一致。
- Agent 自定义环境合并后移除供应商 API Key，避免本机 OAuth 登录被旧环境变量覆盖。
- 归档前显示确认说明；取消不修改数据，确认时先停止进程，再隐藏会话，不删除项目目录。
- 开发运行入口在每次重建前关闭旧实例，打包 SwiftTerm 资源、临时签名并校验应用包；Codex 的 Run 动作已接入同一入口。
