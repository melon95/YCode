# M1.2 SQLite / JSON 数据兼容验收

状态：**通过**

环境：macOS 26.6.2 arm64；SQLite 系统库；Swift 6.3

## 实现

- `LegacyMigrationService` 以 `SQLITE_OPEN_READONLY` 打开旧库，用 `sqlite3_backup` 取得包含未 checkpoint WAL 的一致性快照。
- 快照先写入同一父目录下的隐藏 staging 目录，转为自包含单文件，再规范化成原生 schema；配置验证通过、manifest 写完后才整目录原子移动。
- 失败、中断、损坏库、未来 schema 或不同来源重复导入时，不覆盖已有目标；staging 会清理。
- 导入保留 `agent_session_id`、`agent_thread_name`、worktree path/branch/base branch、待办状态时间、LSP 与检查点字段。worktree 数据只保存，不执行恢复或删除。
- `PreservingJSONDocument` 修改已知设置时保留未知 JSON 字段；首次导入的 `config.json` 保持原始字节不变。
- 导入目录同时保留只读来源快照 `legacy-source.db`，正式回退仍使用未修改的旧版数据目录。
