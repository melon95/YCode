# M5.1 全量设置、主题、语言、字号及窗口恢复

状态：通过

## 交付物

- `YCodeAppearanceSettings` / `YCodeFontSizes` / `YCodeLocale` / `YCodeThemeCatalog`：原生配置层读取并保存 `theme`、`locale`、`font_sizes.ui/editor/terminal`。
- 设置窗口外观页：主题、语言、界面/编辑器/终端字号可编辑；未知主题 ID 原样保留。
- 设置窗口键盘页：展示已迁移快捷键，不提供原版不存在的可编辑快捷键开关。
- 工作区运行时加载外观配置：界面、编辑器、终端字号保存后刷新；窗口 frame 继续由 `NativeWindowStateBridge` 保存/恢复并限制到当前屏幕可见区域。
- 主题色板接入：主窗口 tint/background、终端前景/背景/光标/选择色、编辑器背景/文本/插入点与基础高亮使用 `YCodeThemeCatalog`。
- 语言切换接入：主窗口、设置、终端/文件/编辑器/Git/Todo/历史/用量/通知/语言服务/集成/关注收件箱等已迁移界面通过 `YCodeLocalization` 按 `locale` 刷新。
- 配置测试：保存设置保留未知字段，字号按 8–32 pt clamp，旧主题/未知主题可 round-trip。
