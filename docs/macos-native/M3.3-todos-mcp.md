# M3.3 待办界面与 Swift Todo MCP

日期：2026-09-16
状态：通过

## 实现结果

- 原生 SQLite 待办仓储支持创建、改名、状态流转、删除和项目内排序；写操作使用事务，项目、标题、状态与排序输入先验证再落库。
- `todo → doing`、`doing → done` 分别写入开始和完成时间；重复设置同一状态不重写时间戳，重新打开已完成项时保留历史时间。
- SwiftUI 待办面板支持快速添加、双击改名、队列/进行中切换、完成/重新打开、上下排序和删除确认，并显示三类数量及相对时间。
- `ycode-mcp` 已由 Swift 实现，通过换行 JSON-RPC stdio 提供 `list_todos`、`add_todo`、`update_todo`、`delete_todo`；优先按终端 ID 路由项目，缺失时按规范化工作目录解析。
- Agent 启动环境注入 `YCODE_NATIVE_DATA_ROOT`，MCP helper 与应用读取同一原生数据库；面板定时刷新，因此 helper 的外部修改无需重开面板即可出现。
- 设置 → 集成可读取、注册和取消注册 Claude Code/Codex 的 `ycode-todos`；操作只管理自己的条目，保留其他 MCP 配置，并在首次修改前写入一次 `.ycode.bak` 备份。

## 并发与失败边界

- 12 个独立 SQLite 连接并发创建 12 项，最终 ID 唯一，排序值恰为 `0...11`，没有重复或缺口。
- 非法项目、空标题、非法状态以及缺失/重复/外来 ID 的排序请求均返回错误，操作前后数据完全一致。
- 终端 ID 路由优先于当前目录；没有终端上下文时，项目目录和已有 worktree 目录都可解析，未知目录明确失败。
