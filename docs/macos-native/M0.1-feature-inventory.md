## 4. 持久化面（SQLite → Swift）

数据库 12 个迁移，当前有效表：`sessions`、`projects`、`lsp_installations`、`project_todos`、`session_checkpoints`（`events`/`permissions`/`session_transcript_chunks` 已在 0003/0006 删除，原生版不复活）。

路径事实：`ProjectDirs::from("dev", "ycode", "ycode")`，Tauri identifier 为 `dev.ycode.app`。**这两者不同**，M1.2 必须以前者为准解析实际数据目录，不能用 bundle id 推。

| 表 | 关键列（必须保 ID 与语义） | 目标步骤 |
|---|---|---|
| `projects` | `id` / `name` / `repo_path` / `created_at` / `isolate_sessions` | M1.2 / M1.3 |
| `sessions` | `id` / `title` / `agent_profile` / `agent_session_id` / `agent_thread_name` / `project_id` / `last_exit_code` / `created_at` / `updated_at` / `archived_at` / `worktree_path` / `branch` / `base_branch` | M1.2 / M2.2 |
| `project_todos` | `id` / `project_id` / `title` / `status` / `sort_order` / `started_at` / `done_at` / `created_at` / `updated_at` | M1.2 / M3.3 |
| `lsp_installations` | 安装记录 | M1.2 / M4.4 |
| `session_checkpoints` | `id` / `session_id` / `project_id` / `sequence` / `commit_sha` / `ref_name` / `kind` / `source` / `event_kind` / `body_preview` / `created_at` | M1.2 / M4.6 |

**WebView localStorage 单列迁移**（第 6 节要求，不在 SQLite 内）：
