# M2.4 项目辅助 Shell 与分屏验收

状态：**通过**

环境：macOS 26.6.2 arm64；Swift 6.3；SwiftTerm 1.20.0；独立测试数据目录

## 实现

- 每个项目拥有独立、仅在本次应用运行期间保留的 Shell 分屏树；首次打开终端面板时在项目根目录启动用户的交互式登录 Shell。
- 支持向左、向右、向上、向下分屏；每个叶节点拥有独立 PTY、PID、输入和 256 KiB 回放缓冲。
- 分隔条可拖动，比例限制在 10%–90%；分屏树与比例按项目保留，切换项目只隐藏视图，不停止后台 Shell。
- 关闭整个终端面板不停止 Shell；关闭单个分屏会终止且只终止对应进程，最后一个分屏不能关闭。
- 删除项目或退出应用时回收对应 Shell；Shell 退出后可从原位置重新启动。
- Shell 复用 M2.3 的原生 SwiftTerm 输入、尺寸同步、复制粘贴、链接和回放桥接，不创建第二套 Web/PTY 通道。
