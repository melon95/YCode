# M4.5 Git 状态、Diff、提交与普通分支

状态：通过

## 交付物

- `YCodeGitService`：原生 Swift Git 服务，覆盖状态、diff、逐块 patch、暂存、取消暂存、丢弃、提交、分支列表/切换、fetch/pull/push。
- `ChangesPanelView`：原生变更面板，展示当前分支、ahead/behind、文件状态、diff、暂存/取消暂存/丢弃/提交和远端操作入口。
- `GitServiceTests`：使用临时仓库和本地 bare remote 做独立 Git 查询核对。

## 验收范围

| 能力 | 验收结果 |
|---|---|
| Git 状态 | `git status --porcelain=v1 -z --branch --renames` 解析普通修改、未跟踪、重命名和二进制变更。 |
| Diff | `git diff --no-ext-diff --binary` 支持工作区和 staged fallback。 |
| 逐块操作 | `git apply` 只应用传入 patch；测试先还原文件，再应用选中 patch 并核对磁盘内容。 |
| 暂存 / 取消暂存 / 丢弃 | 用独立 `git diff --cached --name-only`、`git status --porcelain` 和文件存在性核对；未跟踪文件走 `git clean`，跟踪文件走 `git restore`。 |
| 提交 | 拒绝空提交信息；提交后用独立 `git status` 核对剩余变更。 |
| 普通分支 | 本地分支列表和 checkout 通过 `git branch --show-current` 核对。 |
| fetch / pull / push | 本地 bare remote 覆盖 fetch 和 push；首次 push 无 upstream 时设置 `--set-upstream origin <branch>`。 |
