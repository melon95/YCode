## 实现结果

- 每个项目最多对应一个独立 `NSWindow`；重复打开会激活已有窗口，关闭后会从窗口注册表移除。
- 项目窗口锁定到指定项目，并显示独立标题；窗口可从 macOS“窗口”菜单切换。
- 全局菜单和快捷键通过窗口标识只投递给当前关键窗口，避免多个工作区同时响应。
- 同一个 Agent 运行时可同时连接多个 SwiftTerm 视图，主窗口与项目窗口之间不会争抢终端输出。
- 只有主窗口保存全局窗口尺寸和位置，项目窗口不会覆盖主窗口状态。
