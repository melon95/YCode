# M2.1 Agent 配置与启动环境验收

状态：**通过**

环境：macOS 26.6.2 arm64；Swift 6.3；原生开发数据副本

## 实现

- 原生 Agent 目录默认提供 Claude Code、Codex，并可检测 Gemini CLI、Cursor Agent、Aider、Goose；未安装命令允许先保存，启动时返回明确的“找不到命令”错误。
- Agent 设置支持添加、编辑、移除自定义配置，包括稳定标识、显示名、命令、逐行参数及 `KEY=VALUE` 环境变量；未知图标使用首字母占位。
- 启动服务按旧版顺序合并应用环境、Agent 环境、终端能力、代理和 YCode 保留变量，再通过 `$SHELL -l -i -c 'exec …'` 启动；所有命令和参数进行 POSIX 单引号转义。
- 强制设置 `TERM`、`COLORTERM`、`CLICOLOR` 等终端能力并移除 `NO_COLOR`；`YCODE_TERMINAL_ID` 及可选 socket 路径不能被自定义环境覆盖。
- 代理支持关闭、跟随 macOS 系统和手动三种模式。系统模式只补缺项，手动模式覆盖继承值，同时写入大小写变量；PAC 能被识别并明确提示无法转换为环境变量。
- 配置写回保留未知顶层、Agent 内部及代理字段。`$变量名` 仅在启动时解析，原占位符保持在配置中，解析后的敏感值不记录也不回存。
