# M5.2 全量功能回归与性能稳定性

状态：通过（按 2026-09-20 产品优先级调整：保留语法高亮，LSP 语义交互不作为发布阻塞项）

## 交付物

- `scripts/run_regression.sh`：统一执行全量 Swift 测试、开发应用构建、深度签名检查，以及 quick / performance / soak 探针。
- `YCodeStabilityProbe`：同时运行 4 个持续输出终端，循环执行编辑、语法高亮与真实历史搜索，并记录终端存活、输出字节和 physical footprint。
- `YCodeLaunchProbe`：复用同一隔离数据目录执行 5 轮候选包冷启动，以实际可见 layer-0 窗口记录首窗时间；保留辅助功能权限不足导致的口径差异。
- `YCodeTerminalProbe`：通过真实 SwiftTerm PTY 输出 20,000 行，验证序号、UTF-8 中文、shell 计时和输出后 footprint。
- `scripts/run_p4.sh`：固定使用 M0.2 的 S-large / S-small / S-empty cwd、`terminal` 查询和原始阈值；每组执行 1 轮冷缓存加 5 轮正式样本，严格检查恰有 6 条连续编号记录、输出字段与数值格式、样本内计数稳定性，再计算中位数并输出环境、阈值和通过/失败摘要，缺轮或缺失指标不能误通过。
- `scripts/prepare_m52_visual_fixture.sh`：生成一次性数据目录和临时 Git 项目，内含可控 Agent、中文/空格路径、Markdown/SVG/PNG/损坏预览、大文件及 staged/unstaged/untracked 状态；本轮有写入风险的可视操作只针对该夹具。
- `scripts/verify_soak_report.sh`：对完成后的 JSONL 做结构化验收，要求恰有一个末行完成摘要、时长不少于 7,200 秒、迭代从 1 连续到摘要值、4 个终端全程存活、命中数稳定、elapsed 与终端字节严格递增、footprint 字段有效；摘要的 warm、最终值、全程峰值及各增量还必须与原始样本重新计算结果一致，并另外输出全程最低值、前后半程中位数差与线性趋势，避免仅凭随机时点的最终值判断持续泄漏。趋势只作为证据记录，不另造计划外阈值。
- `scripts/verify_m52_checklist.sh`：从 M0.1 权威清单重新计算范围，要求 112 项首版功能和 6 项禁用占位在 25 个可视场景中各出现一次；`coverage` 与 `complete` 均已通过，证明无漏项或重复项。（2026-09-20 前为 117 项 / 26 场景，LS.3–LS.7 移入后置范围 LD 后同步调整。）
- `scripts/check_macos_migration_text.sh`：除常规 `git diff --check` 外，对尚未纳入 Git 跟踪的 macOS 源码、脚本和原生迁移文档逐文件执行空白错误检查；当前覆盖 147 个未跟踪文本交付物，避免 Git 折叠显示整个新目录时漏检。
- `scripts/verify_release_candidate.sh`：同时检查候选 app 与 ZIP 解包副本的深度签名、版本/构建号/最低系统/`ycode://`、主程序和 4 个 helper 及 Sparkle 的 universal2 架构、ZIP 完整性和包内二进制字节一致性；prepare 包若误带更新 feed 或公钥会失败，正式口径还会拒绝缺少 Developer ID、Hardened Runtime、安全时间戳或公证票据的包。
- 历史搜索改为限 4 路并发的 1 MiB 流式扫描；搜索不再把全量事件保留在长期缓存中，并在每个会话扫描后释放临时 Foundation 对象。
- 兼容新版 Codex 的 `codex_work_desktop` 来源标识，和旧 `Codex Desktop` 一样排除桌面任务，避免应用把自身任务历史纳入搜索并在长测期间持续扩大样本；ASCII 查询改用跳表匹配。
- 无头 runtime 不再保留第二份 10,000 行滚动缓冲；256 KiB 原始回放缓冲保持不变，可见 `TerminalView` 仍保留自己的滚动历史。
- 原生编辑器只在内容、语义标记、路径或外观实际变化时重新高亮，避免 SwiftUI 普通刷新反复改写大型 `NSTextView` 的全部属性并触发布局循环。
- 首窗先显示原生占位界面，下一次运行循环再构造同步数据服务和完整工作区，避免初始化期间无可见反馈。
- 终端画布把“新建窗格”和“替换当前窗格”拆为独立、无副作用的路由规则：新会话在未满 4 格时扩展画布，侧栏/关注/已有历史会话选择只替换焦点格；路由本身不启动或停止 Agent 进程。
