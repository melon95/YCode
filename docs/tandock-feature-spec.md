# Tandock 产品范围

更新：2026-10-18。本文以 `main` 的 CLI 工作台为基线，不将独立分支中的实验功能列入当前交付范围。

## 产品定位

Tandock 是 macOS 原生多项目 Agent 工作台。用户使用已经安装并登录的 Claude Code、Codex、Pi 或自定义 CLI，在同一个窗口组织会话、查看文件、审阅改动和管理待办。

每个 CLI 保留自己的引擎、工具、配置、登录与历史。Tandock 负责项目、终端进程、画布和辅助面板，不接管模型服务或订阅账号。

## 当前功能

| 功能 | 范围 |
| --- | --- |
| 项目与会话 | 添加本地项目，配置及启停 Agent；停用保留配置和已有会话；搜索、置顶、归档、恢复会话，以及独立项目窗口 |
| 多会话画布 | 顶部标签页和最多四个分屏；跨项目摆放会话，切换布局时保留终端进程 |
| CLI 交互 | 使用真实 PTY 终端输入，保留 CLI 自身的命令、确认和回复方式 |
| 文件与编辑 | 文件树、预览和固定标签；基础语法高亮、手动编辑与保存，以及外部修改冲突处理 |
| 文件预览 | Markdown、SVG、图片及文本预览 |
| Git 审阅 | 工作区 diff、目录树、逐块暂存、提交、普通分支操作及会话检查点 |
| 待办与集成 | 待办队列、MCP 待办工具、Agent hook 和系统通知 |
| 需关注 | 按会话汇总审批提醒（待核实）、本轮结束未读和启动／退出异常；显式已读与收起、多窗口同步、活跃会话定位；退出项独立恢复 |
| Skills 与 MCP 开关 | 在设置中按 CLI 查看全局技能和 MCP 配置、完整来源路径与停用数量，支持 CLI 允许的启停；不展示或修改项目配置，不提供新增、编辑或删除 |
| 历史与用量 | 读取对应 CLI 的本地记录；实际能力取决于 CLI 提供的数据 |
| 界面设置 | 主题、语言、界面与编辑器及终端字号；可组合的文件、变更、待办、项目终端和需关注面板；窄窗以选择器切换，保留打开顺序 |
| 应用维护 | 本地设置、数据兼容、构建与签名；更新能力以已配置的发布渠道为准 |

## 使用流程

1. 添加项目目录，选择已经配置的 CLI 创建会话。
2. 在 CLI 终端中交代任务；通过侧栏和画布切换项目与会话。
3. 在原终端处理 CLI 的确认或追问，使用文件、Git、待办和项目 Shell 辅助检查。
4. 根据实际文件和运行结果验收，再决定提交、继续、归档或关闭会话。

## 实现边界

- 会话使用原 CLI 的恢复标识和历史，不在不同引擎之间冒充无损恢复。
- CLI 退出（包括 `/exit`、崩溃、非零退出和信号终止）后自动关闭该会话在各窗口中的窗格，保留会话记录、未读结果和异常提醒；主动重启会话时保留窗格，启动失败仍在原位显示原因。
- 窗格标题右键、标题末尾三个点和会话标签菜单统一为「置顶／取消置顶、重命名、归档」；关闭并停止使用 ×，终端查找使用 ⌘F。
- 普通分支操作与检查点保留；worktree 的创建、隔离、合并与自动清理不在当前实现范围，已有目录和元数据保留；不自动恢复旧隔离会话，也不将其改为主目录会话。
- Computer Use 尚未立项，见[研究状态](computer-use-integration-plan.md)。会话界面与统一输入实验暂缓在 `codex/unified-session-entry`，不作为主线待办或发布门槛。
- 不新增模型服务、API 节点管理、订阅登录、账号池或内置反向代理。
- 关注消息仅在应用进程内存中保留，按数据根隔离。主窗口汇总全部项目，项目窗口范围固定；活跃会话的结束通知整张卡片可点击，定位会话并标记已读，无需底部按钮；已退出会话的结束通知点击内容展开全文，仅保留「标记已读」，恢复会话从会话列表操作。在对应运行中继续输入也会标记结果已读，单纯选中与普通输出不会。审批提醒由用户收起、适用的本轮结束事件或运行结束清除；较新和其他明确轮次的提醒保留，不支持面板内批准。Pi / 自定义 CLI 仅有启动与退出事实。旧运行缺少代次时，需要用户恢复后接入，不自动重启任务。
- 模型回复结束不等于用户任务已经验收；文档、原型、构建、实际 CLI 行为和发布状态分别记录。
- Skills/MCP 开关写入各 CLI 自身配置，在新建或重启会话时生效，不表示服务已连接。覆盖 Claude Code、Codex、Grok 的本地 MCP，以及上述 CLI 和 Pi 的本地技能；不管理插件市场、云端连接器或组织策略。Claude MCP 开关按项目保存，因此本页只读展示其全局配置，批准仍由 CLI 处理。Grok 全局禁用名单中的 MCP 只读；Pi 的独立全局技能来源分别展示。显式配置根使用绝对路径，无法确定路径含义时保持只读。无法安全修改的内联 TOML 保持不变并报告错误。
